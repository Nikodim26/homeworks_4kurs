# Приложение E-commerce
## Данный проект предназначен для электронной торговли (или электронной коммерции)
class Category создает именyованый объект - перечень продуктов
class Product создает именyованый объект - продукт, один из, входящих Category
Функция reading_file создает объекты Category и Product путем считывания данных с файла.
Классы Smartphone и LawnGrass являются представителями Product
Добавление продуктов в Category происходит с учетом соответствия определенным классам
Суммирование продуктов происходит с учетом соответствия определенным классам
При создании продукта в консоль выводится информация о нем
Абстрактный класс является шаблоном для Product
## Установка
